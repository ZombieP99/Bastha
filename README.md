# بسطة | Bastha

واجهة مشروع تخرج لمقارنة عروض المتاجر المحلية، باللغتين العربية والإنجليزية.

## التشغيل

- Node.js 20.9 أو أحدث (يفضل إصدار LTS مدعوم).
- تثبيت الاعتماديات: `npm ci`.
- انسخ `.env.example` إلى `.env.local` واضبط `NEXT_PUBLIC_API_URL`.
- التطوير: `npm run dev` ثم افتح `http://localhost:3000/ar`.
- التحقق: `npm run lint` ثم `npm test` ثم `npm run build`.
- تشغيل نسخة الإنتاج بعد البناء: `npm start`.

التقنيات: Next.js 16.2.10، React 19، TypeScript، Tailwind CSS 4، Zustand، Axios، Framer Motion.

## الميزات المرتبطة بالـAPI

تسجيل الحساب والدخول، عرض المتاجر والمنتجات ومقارنة العروض، سلة التسوق، الاستلام والتوصيل، الطلبات وتفاصيلها، تقييمات المتاجر، وإدارة عروض التاجر والطلبات الواردة. تستخدم الواجهة مسارات الـAPI الموثّقة؛ يلزم تشغيل الخادم وتوفير حسابات وصلاحيات صحيحة لاختبار عمليات الحفظ الفعلية.

المفضلة محفوظة محليًا على الجهاز وتُمسح عند تغيير جلسة الحساب. ليست خدمة مزامنة بين الأجهزة.

## البيئة

| المتغير | الغرض |
| --- | --- |
| `NEXT_PUBLIC_API_URL` | عنوان الـAPI، شاملًا `/api`، دون شرطة مائلة أخيرة |
| `NEXT_PUBLIC_SITE_URL` | عنوان الموقع المنشور لملفات الفهرسة |
| `GEMINI_API_KEY` | مفتاح الخادم لخدمة المحادثة الاختيارية |
| `GEMINI_MODEL` | اسم نموذج متاح في حساب Google المستخدم |

المحادثة تتطلب تسجيل الدخول وإعداد المفتاح والنموذج. لديها حدود إدخال واستخدام داخل عملية الخادم؛ عند نشر عدة نسخ، يجب إضافة حد مشترك في البوابة أو التخزين الخارجي. لا تملك وصولًا مباشرًا إلى أسعار المتاجر والمخزون أو تفاصيل الطلبات.

يتطلب البناء اتصالًا بـGoogle Fonts لتنزيل الخطوط عبر `next/font`، أو تهيئة خطوط محلية في بيئة النشر المغلقة.

## خدمات تتطلب تنسيقًا مع مسؤول الـBack-end

- استقبال رسائل الدعم: لا يوجد عقد موثّق للخدمة؛ نموذج الإرسال معطّل وواضح للمستخدم.
- تعديل الحساب واستعادة كلمة المرور: يحتاجان مسارات موثّقة؛ لا يُعرض نجاح وهمي.
- الدخول الاجتماعي والنشرة البريدية غير مفعّلين.
- تقارير مبيعات شاملة تحتاج خدمة إحصاءات؛ أُزيلت الأرقام الثابتة.
- مسارات الإشعارات تحتاج تأكيدًا من الخادم؛ الفشل ظاهر ولا يُعتبر نجاحًا.
- السماح بمصادر صور جديدة يتطلب إضافتها إلى `next.config.ts` بعد اعتمادها.

راجع `IMPLEMENTATION_STATUS.md` لنتائج التحقق وحدود التسليم. لا تحفظ أسرارًا أو حسابات اختبار خاصة في Git.
